# OutageIQ

OutageIQ is a GIS-based storm outage prediction dashboard that helps utilities identify high-risk outage areas before severe weather events.

## Features

- Interactive ArcGIS outage risk map
- Risk levels by service area: Low, Medium, High, Critical
- Weather, vegetation, flood, and infrastructure-based risk scoring
- Customer alert preview
- Crew recommendation workflow
- Proactive storm response dashboard

## Tech Stack

- React + Vite
- Tailwind CSS
- shadcn/ui
- ArcGIS Maps SDK for JavaScript

## Project Goal

OutageIQ helps utility teams move from reactive outage response to proactive storm preparation by visualizing outage hotspots and recommending early actions.
